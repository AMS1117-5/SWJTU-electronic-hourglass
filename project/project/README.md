# 电子沙漏 V1.0 使用与构建

## 1. 当前版本

正式版功能：

- 上电默认沙漏，24 颗沙粒，按姿态初始化到上方沙仓。
- 连续沙量与粒子动画分离；竖直按设置时间流完，倾斜减速，水平暂停，翻转反流。
- 任意一仓从有沙变成空仓时，自动播放约 5 秒旋律；上电空仓和持续空仓不重复触发。
- 32 颗粒子的电子海洋，支持倾斜、翻转和摇动扰动。
- 四项菜单：沙漏、海洋、时间设置、亮度设置。
- 时间：整轮 30～240 秒，步进 30 秒，默认 240 秒；每颗间隔对应 1.25～10 秒。
- 亮度：MAX7219 原生 0～2 档，步进 1，默认 0；0 是最低亮度，不是熄屏。
- 菜单/设置暂停物理模拟，切换功能保留各自粒子状态；返回后继续，不补算暂停时间。
- 设置仅保存在 RAM，复位/重新上电恢复默认；不写 Flash。

显示方向、MPU6050 重力方向和海洋观感已经用户实机确认。
完整菜单版本已通过 11 项测试及三种固件构建；后续 30 秒步进和空仓提示规则修改，
按用户要求只构建 Release，未重新运行测试。

## 2. 正向和按键

正向：**充电接口朝下、板子竖立、LED 面朝你**。
显示器分上面、下面两块点阵。

- K1 = PA1，低电平按下。
- K2 = PA0，低电平按下。
- 短按在松开后识别；长按约 700 ms 后识别一次，松开不再产生短按。

| 页面 | K1 短按 | K2 短按 | K1 长按 |
|---|---|---|---|
| 沙漏 / 海洋 | 无操作 | 无操作 | 打开主菜单 |
| 主菜单 | 上一项，循环 | 下一项，循环 | 确认 |
| 时间设置 | 整轮增加 30 秒 | 整轮减少 30 秒 | 保留设置，返回菜单 |
| 亮度设置 | 增加 1 档 | 减少 1 档 | 保留设置，返回菜单 |

K2 长按暂无功能。正式版正常界面不会因短按而重置沙子或播放测试音。

## 3. 主菜单

上屏显示图标，下屏显示编号，底部闪点表示当前选项位置：

| 编号 | 图标 | 功能 |
|---|---|---|
| 1 | 沙漏 | 返回/进入沙漏 |
| 2 | 水滴 | 返回/进入电子海洋 |
| 3 | 时钟 | 时间设置 |
| 4 | 太阳 | 亮度设置 |

从沙漏打开菜单时选中 1，从海洋打开菜单时选中 2；设置页返回后仍选中该设置项。

例如从沙漏调亮度：

1. 长按 K1 打开菜单，显示沙漏和 `1`。
2. 短按 K1 一次循环到太阳和 `4`。
3. 长按 K1 进入亮度设置，短按 K1/K2 调节，立即看到变化。
4. 长按 K1 返回菜单；短按 K2 一次到 `1`，长按 K1 返回沙漏。

## 4. 时间设置

时间设置页显示**整仓流完的标准时间**，不是当前剩余时间：

- 上面点阵：两位分钟。
- 下面点阵：两位秒数。
- 默认上面 `04`、下面 `00`，即 `4:00`。

每次按键把整轮时间增减 30 秒。内部使用毫秒，24 颗沙粒的间隔可以不是整数秒：

| 单粒间隔 | 显示的整轮时间 |
|---:|---:|
| 1.25 秒 | 00:30 |
| 2.50 秒 | 01:00 |
| 3.75 秒 | 01:30 |
| 5.00 秒 | 02:00 |
| 6.25 秒 | 02:30 |
| 7.50 秒 | 03:00 |
| 8.75 秒 | 03:30 |
| 10 秒 | 04:00 |

达到上下限后继续按不会越界或循环。10 秒是标准竖直的**设置上限**，
倾斜、水平暂停和粒子碰撞可能延长实际过砂间隔。

改变时间不会重装或清空沙子，只改变后续流速。若当前只剩半仓，调到 `00:30` 后，
剩余部分通常约需 15 秒，而不是重新等完整 30 秒。

## 5. 亮度设置

上屏太阳图标、下屏数字 `0` / `1` / `2`。按键后同时更新两颗 MAX7219 的亮度寄存器，
画面和粒子状态保留。上下限停止，不循环。退出设置后，所有功能沿用新亮度。

## 6. 完成旋律与异常显示

任意一仓最后一颗沙粒跨过瓶颈、该仓从有沙变为空仓时，就在当前画面播放约 5 秒旋律。
判断与最初从哪个仓开始无关，中途翻转、沙子流回原仓也会提示，无需再等一个完整设置周期。
设定时间仅控制过砂流速；播放期间采样、按键、显示和菜单继续工作。
上电时本来就空的那仓不提示，持续空仓不重复提示；有沙重新进入后再流空，才产生新的提示。
正放、倒置均可自然开始/继续过砂，不需要重置。

传感器错误时，功能页上屏显示 `E`，下屏显示错误编号：

| 编号 | 含义 |
|---|---|
| 1 | I2C 未应答、忙或超时 |
| 2 | WHO_AM_I 不符合 MPU6050 |
| 3 | 没有持续收到新数据 |

数据无效时暂停物理更新，后台定期重试；恢复后继续原状态。错误期间仍可长按 K1 操作菜单和设置。

## 7. 整体体验步骤

1. **启动与显示**：确认上电进入沙漏，拿正后装入上仓；平放上电时先显示轮廓，竖起后开始。
2. **四项菜单**：验证循环选择、长按确认、松手不误触发下一项。
3. **快速计时**：将时间设为 `00:30`，先等当前轮流完，再翻转满仓测一次约 30 秒的完整转移。
4. **保持进度**：流到一半进入菜单，等待后返回；再改变时间，确认沙量和位置均保留。
5. **亮度**：测试 0→1→2 和反向调节，确认上下限、即时预览和返回后的保留。
6. **海洋**：确认模式切换、倾斜/摇动、返回原状态。
7. **旋律并发**：报警时打开菜单并调节亮度，确认音符和界面正常，旋律结束后不重复触发。
8. **复位默认**：确认重新上电恢复每颗 10 秒、亮度 0。

## 8. 构建与烧录

### Windows VS Code

打开外层工程目录 `D:\SWJTU\welcome_gift\project`（包含 `AGENT.md` 和 `.vscode` 的目录）。
工作区 `.vscode/settings.json` 已指定 MSYS2 ARM GCC、Windows CMake、Cortex-M0/Thumb，
并通过 CMake Tools 和 Release 的 `compile_commands.json` 提供头文件路径、宏与 IntelliSense 配置。

修改配置后，在命令面板执行 `Developer: Reload Window`，然后选择
`CMake: Select Configure Preset` → `Release`，执行 `CMake: Configure`。
若仍显示旧 IntelliSense 缓存，可执行 `C/C++: Reset IntelliSense Database`。

以下命令在本文件所在的固件目录执行。工具链固定使用 `C:\msys64\ucrt64\bin`。
Preset 会设置 Windows 子进程的 PATH，供 ARM GCC 加载自身程序和依赖 DLL。

### WSL：正式 Release

```bash
/mnt/c/msys64/ucrt64/bin/cmake.exe --preset Release
/mnt/c/msys64/ucrt64/bin/cmake.exe --build --preset Release
```

产物：

```text
build/Release/project.elf    ELF 固件
build/Release/project.hex    带地址的 HEX 烧录镜像
build/Release/project.bin    原始二进制镜像
build/Release/project.map    链接映射
```

使用 STM32CubeProgrammer / ST-Link 加载 `.hex` 或 `.elf`；若选择 `.bin`，起始地址为 **0x08000000**。
Debug 构建使用同一套正式菜单，命令中的 `Release` 换为 `Debug`。

### 独立诊断版本

```bash
/mnt/c/msys64/ucrt64/bin/cmake.exe --preset Diagnostic
/mnt/c/msys64/ucrt64/bin/cmake.exe --build --preset Diagnostic
```

产物在 `build/Diagnostic/`。此版本保留开发期间的长按循环：
沙漏 → 海洋 → 光点/三轴 → 四角 → LED/按键 → 沙漏。
沙漏 K2 短按试听旋律，海洋 K2 短按重新散布粒子。
诊断版本使用默认时间和亮度，正式版的菜单与设置在 Release / Debug 中。

### 主机测试（WSL 原生 CMake / GCC）

```bash
cmake -S tests -B build/host-tests -G "Unix Makefiles" -DENABLE_SANITIZERS=ON
cmake --build build/host-tests -j 4
ctest --test-dir build/host-tests --output-on-failure
```

11 项测试涵盖驱动、物理、设置/UI 和真实按键到应用状态机的集成路径，启用地址及未定义行为检查。

当前构建资源占用（链接器报告，RAM 含预留堆栈区域）：

| 版本 | Flash / 64 KiB | RAM / 8 KiB |
|---|---:|---:|
| Release | 18,360 B | 2,464 B |
| Debug | 30,232 B | 2,464 B |
| Diagnostic | 19,232 B | 2,496 B |

## 9. 代码入口

- `Core/Src/main.c`：外设初始化和协作式主循环。
- `App/app.c`：正式状态机；`menu.c`、`settings.c`、`ui.c`：菜单、RAM 设置和图标数字。
- `App/hourglass.c` / `ocean.c`：两个物理效果。
- `Physics/motion.c` / `particles.c`：重力转换、摇动强度和粒子网格。
- `Drivers/` 下的自定义模块：按键、显示、MAX7219、MPU6050、蜂鸣器。
- `App/bringup.c` / `imu_test.c`：独立 Diagnostic 版本入口。
- `Config/app_config.h`：已标定方向、低通、默认值与设置边界。

CubeMX 主循环接入代码位于 USER CODE 区，自定义源文件由顶层 CMake 显式登记。
